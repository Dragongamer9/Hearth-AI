Erase this memory for good?

Its text and every correction to it will be wiped from Ithil's memory. A content-free note that you erased something stays in the log.

What erase doesn't reach: backups or copies of the database made earlier, temporary files left by a crash, old data on the disk itself, and other messages that mention the same thing.
